# Coca-Cola Sales Analysis Dashboard | Power BI

## Project Overview

This project presents an interactive sales analysis dashboard developed using Microsoft Power BI. It explores Coca-Cola sales performance through key business metrics, monthly revenue trends, beverage brand performance, and geographical sales distribution.

The dashboard transforms sales data into visual insights that can help businesses understand revenue patterns, monitor product performance, and evaluate regional sales distribution.

## Project Objectives

The main objectives of this project are to:

- Analyze overall sales revenue and units sold.
- Monitor price per unit.
- Explore monthly revenue trends.
- Examine sales performance across different beverage brands.
- Compare sales distribution across geographical regions.
- Visualize sales performance across different states.
- Present business information through an interactive dashboard.

## Dashboard Features

### 1. Key Performance Indicators (KPIs)

The dashboard includes three key performance indicators:

- **Revenue:** Displays total revenue generated.
- **Units Sold:** Shows the total quantity of products sold.
- **Price per Unit:** Provides an overview of product pricing.

### 2. Monthly Revenue Analysis

A column chart is used to visualize revenue across different months.

This helps identify revenue patterns and understand how sales performance changes over time.

### 3. Beverage Brand Analysis

The dashboard includes a beverage brand slicer, allowing users to explore sales information for individual beverage brands.

### 4. Regional Sales Analysis

A regional filter allows users to examine sales performance across different geographical regions.

### 5. Geographical Sales Distribution

A map visual displays sales distribution across states, providing a geographical perspective of the business's performance.
